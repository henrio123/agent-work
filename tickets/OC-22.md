## Goal

Ensure every ticket is persisted on disk and can be re-printed deterministically, so no ticket content can be lost to terminal scrollback or conversation compaction. OC-22 must have a single source of truth ticket file and tools must refuse to proceed if ticket content is missing.

## Non Negotiables

- No ticket may exist only in terminal output
- Ticket must be stored as a file before being displayed
- Printing a ticket must read from the stored file, not from generated console text
- If a ticket ID is printed but no file exists, fail fast with a clear error and next step
- No external npm dependencies
- All tool outputs remain JSON only where applicable

## Steps

1. Create tickets directory conventions and contract
2. Implement ticket-store.js module with resolveTicketPath, readTicket, writeTicket, validateTicketFormat, ensureTicket, guardTicketId
3. Implement tools/ticket-show.sh that calls node script and prints raw ticket text
4. Implement tools/ticket-ensure.sh that validates existence and required headings
5. Implement tools/ticket-guard.sh as anti-truncation guard
6. Add tests covering happy path, missing file, invalid format, guard failure
7. Update SKILL.md with Ticket Persistence section
8. Run tools/test-all.sh and ensure no regressions
